Why this is useful

A slowly changing machine problem (loose mount, worn bearing, a tool that slows when hot) often shows up as more vibration or a new frequency before it stops the line. This turns any phone into a quick check: record a baseline when the machine is healthy, then compare later rounds against it. It also checks that a base is level before you bolt a machine down.

How to use: vibration

  1. Press Start sensors. Rest the phone flat, screen up on a rigid part of the machine (housing, base plate), not on a cover or cable.
  2. With the machine healthy: Save as baseline. Keep the same spot and orientation every time.
  3. Later: Measure & log. The status compares RMS with the baseline: OK below 1.5×, WATCH 1.5–2.5×, ALERT above 2.5×. These are my rule-of-thumb limits, not a standard.
  4. Read the spectrum: a new or taller peak shows which rotating part (Hz × 60 = rpm) is responsible.

How to use: level

  1. Lay the phone flat on the surface, screen up; the bubble moves toward the high side.
  2. For better accuracy press Flip-calibrate: measure, turn the phone 180° on the same spot, measure again. The average is the phone’s own offset; half the difference is the true surface tilt.

Limits you should know

  • Frequency range. Phone browsers sample about 60 Hz (some phones up to 100–200 Hz), so you can only see vibration below half that rate (≈30 Hz at 60 Hz sampling). Faster vibration can show up as a false low-frequency peak (aliasing). The actual rate is shown at the top. That covers slow machines, 600–1800 rpm shafts, press and conveyor cycles, tool-slowdown pulses, and structure sway.
  • Velocity is indicative. It is computed from acceleration over 2 Hz–Nyquist only, so it does not replace an ISO 10816 / 20816 measurement (10–1000 Hz).
  • Sensor noise is about 0.01–0.02 m/s². Below that the screen says QUIET.
  • Mounting matters. Soft pads, cases and cables change the numbers. Compare only like with like.
  • Tilt accuracy is typically ±0.1–0.3° after zeroing or flip-calibration, not a precision-level substitute.
  • Safety. Do not hold the phone against moving parts or place it on hot surfaces.

If sensors don’t start

  • The page must be opened over https (or as a local file in Chrome). Motion sensors are blocked on plain http.
  • iPhone: tap Allow on the motion prompt (Settings → Safari → Motion & Orientation Access).
  • Android: Chrome → site settings → Motion sensors → Allow.
  • No sensor (e.g. desktop)? Use the demo. It is clearly labelled as simulated.
